# LaCalc 🧮

LaCalc, temel matematiksel işlemleri gerçekleştirmek amacıyla C# dili ve Visual Studio 2022 kullanılarak geliştirilmiş bir konsol tabanlı masaüstü uygulamasıdır.

## 🚀 Özellikler
- **Temel Aritmetik:** Toplama, çıkarma, çarpma ve bölme işlemlerini destekler.
- **Kullanıcı Deneyimi:** Basit ve anlaşılır bir komut satırı arayüzüne sahiptir.
- **Algoritma Mantığı:** Hata yönetimi (sıfıra bölme gibi durumlar) ve döngü yapıları üzerine pratik yapılmıştır.

## 🛠 Kullanılan Teknolojiler
- **Dil:** C#
- **IDE:** Visual Studio 2022

## 💻 Nasıl Çalıştırılır?
1. Projeyi bilgisayarınıza indirin (clone).
2. Visual Studio 2022 ile `.sln` dosyasını açın.
3. Uygulamayı derleyin ve başlatın.
